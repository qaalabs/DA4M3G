## DB-TYPES: Database Types Investigation

Lab: docs/day3/db-types.md

- Pairs investigate one of 5 database/storage types: relational (SQL Server + Cloud SQL), NoSQL/document (MongoDB + Firestore), cloud data warehouse (BigQuery + Snowflake), object storage (GCS + S3), distributed/wide-column (Bigtable + Cassandra)
- Each pair prepares to explain: what type it is, what data it stores best, when an analyst would use it
- Sets up why we're moving to BigQuery this afternoon
