## Views - Creating and Using Views

- Trainer: Day 4 01_Views.pptx (10 slides)
- Learners: Day4/Day 4 01_Views.pdf

- A view is a stored SELECT that acts like a table - no speed gain, but simpler and reusable
- ProductsByCategory example: build the query, then wrap it in CREATE VIEW
- Ask why ORDER BY isn't in the view - sort when you use it instead
- Security (PhoneList), WITH CHECK OPTION and update restrictions - keep these brief
