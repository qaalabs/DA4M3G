# Running Queries in BigQuery

Guided walkthrough - trainer runs each query, learners follow along.

**Part 1 - Explore:** COUNT(*) on users and orders, then SELECT * LIMIT 10

**Part 2 - Filter/sort:** Orders WHERE status = 'Shipped', products WHERE category = 'Jeans'

**Part 3 - Aggregations:** Orders by status, avg sale price by category, top 10 brands

**Part 4 - Join (light):** orders JOIN users to add customer name

Prompt after each group: does this feel familiar? what changed?
