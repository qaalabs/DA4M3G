# Database Types Investigation

## Beyond the Relational Database

A data analyst doesn't always get to choose where the data lives - you need to recognise different types of database and know what each one is good for.

In pairs, investigate the two tools below and be ready to explain them to the room.

Pair 1: SQL Server + Cloud SQL ~ *relational*

Pair 2: MongoDB + Firestore ~ *NoSQL / document*

Pair 3: BigQuery + Snowflake ~ *cloud data warehouse*

Pair 4: Google Cloud Storage + Amazon S3 ~ *object storage*

Pair 5: Bigtable + Cassandra ~ *distributed / wide-column*
