# BigQuery Tasks - Aggregations

Write a query to answer each question. All tables are in `bigquery-public-data.thelook_ecommerce`.

---

## Level 3: Aggregations

**Task 11** - How many orders has each user made? Show the top 20.

**Task 12** - What is the total revenue (sale price) by product category?

**Task 13** - What is the average sale price per order status?

**Task 14** - Which country has the most users?

**Task 15** - How many products does each brand have? Show only brands with more than 10 products.

> Hint for Task 15: `GROUP BY` filters rows before grouping. To filter after grouping, use `HAVING`.
