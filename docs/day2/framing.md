# Framing - Yesterday Local, Today Cloud

Frame it as a **continuation**, not a new course.

Start with:

> "Yesterday we worked with SQL in a local database environment. Today we are going to move that thinking beyond the local machine. The important point is not that you become experts in any particular cloud platform. The point is that SQL, tables, relationships and analysis do not disappear when the data lives somewhere else."

Then pause and ask:

> "When the database is no longer local, what do you think changes?"

Let them answer. Capture just a few. Then say:

> "Most of the things that change are around the database - access, location, permissions, scale, sharing. The SQL thinking itself stays surprisingly familiar."

---

## The opening idea

You want them to feel:

> "I am not starting again."

Show this comparison:

| Yesterday | Today |
|-----------|-------|
| SQL in SSMS | SQL in cloud platforms |
| Local database | Data hosted elsewhere |
| Query results in a grid | Query results in a grid or report |
| Tables, rows, columns | Tables, rows, columns |
| SELECT, WHERE, JOIN, GROUP BY | SELECT, WHERE, JOIN, GROUP BY |

Then land on:

> **"The platform changes. The SQL thinking travels with you."**

---

## Opening question

Use this one:

> "Which parts of yesterday's SQL do you think will still matter today?"

This gets them to name the transfer:

- Tables
- Columns
- Data types
- Filters
- Joins
- Aggregations
- Checking results
- Asking good questions

Then say:

> "Exactly. Those are the things we are carrying with us today."

---

## Day purpose

Put this on the slide:

> **Today's question:** Where can SQL take us when the data is not just sitting on our own machine?

> By the end of today, you should be able to recognise familiar database and SQL ideas across different cloud-style environments.

---

## What not to say

Avoid opening with:

> "Today we are doing Google Cloud."

That sounds like a platform course. Better:

> "Today we are taking SQL beyond the local machine. Google BigQuery will be our first example."
