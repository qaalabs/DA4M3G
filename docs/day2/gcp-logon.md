# Logging on to Google Cloud

## Step 1: Go to Google Cloud

Open a browser and go to:

**[console.cloud.google.com](https://console.cloud.google.com)**

## Step 2: Sign in

Sign in with your Google account (the one your trainer added to the course group).

When you are signed in, click **Go to console**.

## Step 3: Switch to the course project

At the top of the page, click the project selector (it shows the current project name or "Select a project").

In the dialog that opens:

- Look for the organisation **ingwane.org**
- Select the project **ingwane-da4m3**

You are now in the right place.

## Step 4: Check you are in the right project

The project name **ingwane-da4m3** should appear at the top of the page.

If you see a different project name, use the project selector to switch.
