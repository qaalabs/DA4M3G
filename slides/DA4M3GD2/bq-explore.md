# Explore ECommerce Dataset

Learners find and pin `bigquery-public-data.thelook_ecommerce`.

- Search Explorer panel for `thelook_ecommerce` -- or pin via **+ ADD DATA**
- Expand dataset -- 7 tables (orders, order_items, products, users, ...)
- Click `orders` -- walk through Schema / Details / Preview tabs
- Repeat for `order_items` and `products`

Key question to plant: how do `orders` and `order_items` connect?
